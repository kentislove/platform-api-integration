## 🔄 v2.0 重大變更

### ❌ 舊版規則 (v1.0)

```
庫存 ≤ 2 時:
  → 只有 PChome 下架
  → MOMO 保持上架
  → 同步時間: 5 分鐘
  → 資料庫: MySQL
```

### ✅ 新版規則 (v2.0)

```
庫存 ≤ 2 時:
  → MOMO 和 PChome 都下架
  → 兩個平台庫存都設為 0
  → 同步時間: 1 分鐘
  → 資料庫: Google Sheets
  → 所有異動都發送 Email
```

## 🎯 核心功能

### 1. 自動庫存同步 ⚡

- **同步速度**: ≤ 1 分鐘
- **主庫存**: YAHOO
- **次平台**: MOMO, PChome
- **同步方式**: 自動偵測 YAHOO 庫存變動

### 2. 安全庫存機制 🛡️

```javascript
if (YAHOO庫存 <= 2) {
  MOMO庫存 = 0;
  MOMO狀態 = "下架";
  PChome庫存 = 0;
  PChome狀態 = "下架";
  發送警示Email();
} else if (YAHOO庫存 >= 3) {
  MOMO庫存 = YAHOO庫存;
  MOMO狀態 = "上架";
  PChome庫存 = YAHOO庫存;
  PChome狀態 = "上架";
  發送恢復Email();
}
```

### 3. Email 通知系統 📧

**通知時機**:
- ✅ 所有庫存異動
- ✅ 庫存 ≤ 2 警示
- ✅ 庫存恢復 (≥3)
- ✅ 平台自動上下架
- ✅ 同步失敗

### 4. 完整日誌記錄 📝

- 所有操作都有記錄
- 可追溯每次異動
- 支援篩選與搜尋

## 📊 Google Sheets 資料庫結構

### 8 個工作表

1. **廠商原料號主檔** - 商品基本資料
2. **平台料號映射** - YAHOO/MOMO/PChome 料號對照
3. **主庫存(YAHOO)** - YAHOO 主庫存數據
4. **同步庫存記錄** - MOMO 和 PChome 庫存狀態
5. **訂單記錄** - 三平台訂單資料
6. **同步日誌** - 所有同步操作記錄
7. **庫存警示** - 低庫存警示記錄
8. **系統設定** - 系統參數設定

### 自動觸發器

- **每 1 分鐘**: 檢查庫存變動並同步
- **每 5 分鐘**: 同步訂單資料
- **每 10 分鐘**: 檢查安全庫存規則

## 🆘 常見問題

### Q: 為什麼選擇 Google Sheets?

**優點**:
- ✅ 免費且易於使用
- ✅ 雲端自動備份
- ✅ 多人協作
- ✅ 版本記錄
- ✅ 無需伺服器

**缺點**:
- ❌ 效能限制 (大量資料)
- ❌ Email 配額限制
- ❌ 觸發器執行時間限制

### Q: 可以管理多少商品?

- **少於 1,000 個**: 效能良好 ✅
- **1,000-5,000 個**: 可能需要優化 ⚠️
- **超過 5,000 個**: 建議使用資料庫 ❌

### Q: 資料安全嗎?

- ✅ Google 雲端加密儲存
- ✅ 可設定存取權限
- ✅ 完整版本記錄
- ✅ 可隨時匯出備份
